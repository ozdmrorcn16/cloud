# Slooin

Konum tabanli sosyal uygulama: check-in yap, gorunur ol, populer yerleri
kesfet, yakinindaki insanlarla tanis, sohbet et.

**Projeye yeni giren herkes (insan ya da Claude) once
[`slooin-projesi.md`](slooin-projesi.md) dosyasini okur** - tek dosyalik
devir belgesi: servisler, komutlar, mimari, kurallar ve kaldigi yer.
Ardindan `CLAUDE.md` (kurallar, tuzaklar) ve `docs/konusma-gunlugu.md`
(karar defteri).

- Uygulama: `mobil/` (Expo, iOS + Android + web)
- Site: `site/` (Astro, https://slooin.com)
- Moderasyon paneli: `panel/`
- Veritabani gecmisi: `mobil/supabase/migrations/`
