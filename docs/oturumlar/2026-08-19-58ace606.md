## Sıradaki adımlar (senin yapman gerekenler)

1. Depoyu çek, `pip install -r requirements.txt`, `python -m otomasyon dogrula`
2. Ücretsiz **Pexels** anahtarı al + varsa **ANTHROPIC_API_KEY** → `.env`'e yaz. Bu ikisi kaliteyi en çok yükselten şey.
3. `python scripts/youtube-yetki.py <client_secret.json>` ile bir kerelik yetkilendirme (README'de Google Cloud Console adımları var)
4. İlk videoları `private` olarak yükle, beğendiğini elle aç

Higgsfield adaptörü de var ama REST uçlarını doğrulayamadım, deneysel işaretledim — AI görsel için güvenilir yol şimdilik görselleri `varliklar/gorseller/` klasörüne bırakmak.
