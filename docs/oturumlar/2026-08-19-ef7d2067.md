## Yerelde başlatma — üç yol

**A) Normal oturum + Remote Control açık** (en yaygın)
```bash
cd ~/cloud            # proje dizinin
claude --remote-control
```
Terminalde normal şekilde yazmaya devam edersin, aynı anda telefondan/webden de kontrol edilebilir. İsim vermek istersen: `claude --rc "Cloud projesi"`

**B) Zaten açık bir oturumun varsa**
```

```
veya kısası `/rc`. Mevcut konuşma geçmişini de taşır.

**C) Sunucu modu** (sadece uzaktan kullanacaksan)
```bash
cd ~/cloud
claude remote-control
```
Terminal bağlantı bekler, oturum URL'sini basar; **boşluk tuşu** QR kodu gösterir — telefonla okutup direkt açarsın.
