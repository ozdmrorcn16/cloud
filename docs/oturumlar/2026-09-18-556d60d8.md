Site Astro ve **statik, React yok** (`astro.config.mjs`: `output: 'static'`, bağımlılık yalnızca `astro` + `supabase-js`). Bu yüzden `motion/react` değil, kütüphanenin **vanilla JS** sürümü uyuyor — Astro'nun `<script>` etiketinin içinde doğrudan çalışır, React eklemek gerekmez (2,3 KB mini paket; hukuki sayfaların "JS'siz okunur" şartına da dokunmaz çünkü animasyon süslemedir).

Kurulum (`site/` içinde):

```bash
npm install motion
```

Kullanım, bir `.astro` dosyasında:

```astro
<script>
  import { animate, inView, stagger } from "motion"

  // sayfa acilirken
  animate(".kahraman", { opacity: [0, 1], y: [24, 0] }, { duration: 0.6 })

  // kaydirinca gorunume girince
  inView(".ozellik", (el) => {
    animate(el, { opacity: [0, 1], y: [16, 0] }, { delay: stagger(0.1) })
  })
</script>
```

Kurayım mı? İstersen hemen `npm install motion` çalıştırıp ana sayfada (`[...dil]/index.astro`) ilk animasyonu bağlarım; hangi öğelerin hareket etmesini istediğini söylersen ona göre yaparım.
